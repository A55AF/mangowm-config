# Mangowc Configs
mangowc configuration files based on noctalia shell.

## Structure
├── conf                      Root directory for config files
│   ├── animations.conf       Animations
│   ├── appearance.conf       Appearance of windows (gaps, blur, shadows, etc...)
│   ├── autostart.conf        Autostart Apps (example. noctalia)
│   ├── binds.conf            Keyboard Bindings
│   ├── general.conf          General Settings
│   ├── input.conf            Input devices Settings (touchpad and mouse)
│   ├── layouts               Settings directory for each layout
│   │   ├── dwindle.conf
│   │   ├── master.conf
│   │   └── scroller.conf
│   ├── monitors.conf         Monitors setup
│   └── rules.conf            General rules (windows, tags, etc...)
└── config.conf
